# Performance Report

## Methodology

- Benchmark script: `python scripts/benchmark.py`
- Flow measured per iteration: upload document, poll `/documents/{id}/status` when available, then call `/documents/{id}/mask`
- Results are written to `data/benchmark_results.json`
- This file is regenerated by `scripts/benchmark.py` after each benchmark run
